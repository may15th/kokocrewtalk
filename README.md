# 코코톡 — 코코크루 실시간 메신저

Cloudflare 무료 전용 구성과 로컬 실행·배포·SQLite 이전 절차는 [docs/CLOUDFLARE.md](docs/CLOUDFLARE.md)를 참고하세요. 기존 Python 실행 방식과 데이터는 유지됩니다. Cloudflare 배포에는 대상 계정의 Workers Free 플랜 확인이 필요합니다.

카카오톡의 편리한 대화 흐름을 참고한 **독립적인 코코크루 웹 메신저 프로토타입**입니다. 기존 코코크루 투명 PNG 이모티콘 10종이 내장되어 있으며, **이미지를 사진으로 전송하는 것이 아니라 채팅 화면 내부에서 스티커로 직접 렌더링**해 흰색 사각형 없이 표시됩니다.

## 주요 기능

- 여러 브라우저/사용자가 동시에 참여하는 **실시간 WebSocket 채팅**
- 기본 공개 채팅방 3개, **새 채팅방 생성**, 채팅방 검색
- **코코크루 이모티콘 버튼** → 10종 선택 → 채팅에 투명 스티커 전송
- 닉네임 설정, 접속 인원수 표시, 입력 중 알림, 초대 링크 복사
- 데스크톱/모바일 반응형, 다크 모드
- **SQLite에 메시지 영구 저장** (데이터베이스를 보존하는 서버에서)

## 실행 방법

1. Python 3.10+ 설치
2. 이 폴더에서 터미널 열기
3. `python -m pip install -r requirements.txt`
4. `python app.py`
5. 브라우저에서 **http://localhost:8000** 열기

같은 컴퓨터의 다른 브라우저/시크릿 창에서 각각 **다른 닉네임**으로 접속하면 실시간 대화를 확인할 수 있습니다.

같은 와이파이의 다른 기기에서는 컴퓨터의 사설 IP 주소(예: `http://192.168.0.10:8000`)로 접속할 수 있습니다. Windows 방화벽에서 8000 포트 접속을 허용해야 할 수 있습니다.

## 인터넷에서 여러 사람이 쓰게 하려면

이 코드는 **서버가 실행되어야 하는 웹앱**입니다. ZIP을 각자 열어보는 것만으로는 서로 메시지가 연결되지 않습니다. 인터넷 공개 사용에는 Python + WebSocket을 지원하는 서버에 배포하고 HTTPS 도메인을 연결해야 합니다. 예: Docker 지원 클라우드 서버, VPS 등.

- Docker 배포용 `Dockerfile` 포함
- 서버 환경 변수 `PORT` (기본 8000), `KOKO_DB_PATH` (기본 `chat.db`)
- SQLite를 유지하려면 영구 볼륨을 연결해야 합니다. 여러 서버 인스턴스로 확장할 때는 DB와 실시간 메시지 동기화 구조를 별도로 설계해야 합니다.
- 개발용은 `python app.py`; 단일 서버 프로세스로 사용하세요.

## 주의 / 정식 서비스 전 필요한 것

이것은 **공개 닉네임 기반의 MVP**로 **회원 인증, 개인정보 보호 설계, 채팅 신고/차단, 악성 메시지 필터, 운영자 권한, 서버 측 사용량 제한, 비공개방 권한 검사, 이미지 업로드 보안, 데이터 보존 정책**이 아직 없습니다. 공개 인터넷에서 불특정 다수가 이용하는 서비스로 그대로 운영하지 마세요. 실제 서비스 단계에서는 로그인/인증, 권한, 운영도구, HTTPS, 신고/차단, 개인정보 처리방침 등을 추가해야 합니다.

브랜드/UI는 카카오톡의 기본 채팅 UX를 참고했지만, 명칭과 그림/화면 구성은 코코크루 고유 방식으로 만들었습니다. **코코크루 캐릭터를 공개 서비스에 사용하려면 해당 권리자의 승인을 확인하세요.**

## 코드 구조

- `app.py` — FastAPI, WebSocket, SQLite 저장소, 채팅방 API
- `static/index.html` — 대화방 목록, 채팅창, 이모티콘 패널 등 전체 웹 UI
- `static/stickers/*.png` — 이전에 만든 투명 스티커 10종
- `Dockerfile`, `requirements.txt` — 설치·배포 구성
